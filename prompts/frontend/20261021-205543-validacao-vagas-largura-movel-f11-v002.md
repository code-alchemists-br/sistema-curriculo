## Validação da decisão

### Método proposto sem dependência nova

Ler exatamente features/listar-vagas/ui/TelaVagasGrupo2.css e app/styles/global.css via **node:fs readFileSync com URL relativa ao arquivo do teste**, sem usar cwd implícito nem importar postcss. fs é builtin de Node fornecido pelo Nix; não precisa de pacote. A instalação atual contém tipos Node; o lint usa imports de módulos e não requer expor global process. Não escrever relatório a partir do teste: redigir depois com saídas reais.

Não confiar em import lateral CSS como fonte. Vite tem suporte a ?raw em node_modules/vite/dist/node/chunks/node.js, mas o plugin Vitest CSS também reconhece ids .css com query e pode esvaziá-los (F11). **Não presumir ?raw funcional** nesta configuração nem mudar test.css só para tornar esse caminho possível. fs lê o texto original e evita essa interação.

Analisar cada texto numa CSSStyleSheet construída com replaceSync ou, no fallback público, num style temporário seguido de sheet.cssRules. Extrair type/media.mediaText/selectorText/style.getPropertyValue; não importar internos do jsdom, css-tree ou PostCSS. O global contém @import de tokens: inspecionar separadamente, sem buscar recurso de rede e sem atribuir sua resolução à análise. Tokens não contêm os alvos/breakpoints ensaiados (F7).

Avaliador **de teste**, não produção: aceitar a gramática encontrada `(max-width: <n>rem)` ou px; base rem=16 passada explicitamente; condição widthPx <= n×base. Usar o texto mediaText real extraído, sem hardcode de “ativa” por largura. Para os seletores exatos e propriedades listadas, considerar declarações de base e da regra ativa na ordem de origem. Os casos atuais têm seletores equivalentes e sem !important nos alvos. Não implementar cascata CSS geral: presença de condição não suportada, !important, selector concorrente ou escopo novo para os alvos deve produzir erro explícito de método não suportado, pedindo revisão. Não ignorar seletor/at-rule desconhecido que afete os alvos.

As expectativas da matriz são literais independentes. Asserções devem cobrir **regra base, localização das declarações no bloco de mídia e resultado do regime**, para não aceitar cópia incondicional dos valores móveis. Preservar o CSS real como entrada; uma fixture que transcreva o CSS não é substituto. Whitespace de valores pode ser normalizado sem mudar semântica.
