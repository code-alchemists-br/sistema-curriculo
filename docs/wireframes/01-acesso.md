# Wireframe 01 — Acesso

## Objetivo
Representar cadastro, login e recuperação de senha.

### Login
- E-mail
- Senha
- `Entrar`
- `Esqueci minha senha`
- `Cadastrar uma conta`

### Cadastro
- Nome
- E-mail
- Senha
- Confirmação de senha
- `Cadastrar`
- Retorno para login

### Recuperação
- E-mail
- `Enviar link`
- Retorno para login

## Estados
Campo inválido, credenciais inválidas, carregamento e sucesso.

## Navegação
Após autenticação → Painel inicial.
