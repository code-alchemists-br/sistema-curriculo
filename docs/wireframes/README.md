# Wireframes — Sistema Currículo

## Atividade 2 — Wireframes das páginas

Este pacote documenta visualmente a jornada principal do aluno no Sistema Currículo.

Fluxo:
**Acesso → Painel inicial → Preenchimento → Revisão → Visualização → Exportação → Download**

A representação visual (`wireframes-visao-geral.png`) e os nove arquivos Markdown descrevem as mesmas telas e decisões de navegação.

## Telas
1. Acesso — login, cadastro e recuperação de senha.
2. Painel inicial.
3. Dados pessoais e contato.
4. Formação acadêmica.
5. Experiências profissionais.
6. Informações complementares.
7. Revisão e edição.
8. Visualização do currículo.
9. Exportação, sucesso, falha e download.

## Relação com os casos de uso
- Acesso: UC01 e UC02.
- Formação: UC03.
- Experiências: UC04.
- Revisão: UC05.
- Visualização: UC06.
- Exportação PDF: UC07.
- Exportação DOCX: UC08.

## Regras de escopo
Os wireframes representam exclusivamente a jornada de construção do currículo pelo aluno.

Não fazem parte deste recorte: upload/importação de currículo existente, análise automática, IA, diagnóstico, pontuação, sugestões automatizadas de melhoria, comparação entre currículo original e melhorado, fluxos paralelos de criação/revisão, funcionalidades de recrutador e integração com o Grupo 2.

## Critério de aceite
É possível compreender como o aluno acessa a conta, preenche os dados progressivamente, revisa, visualiza e exporta PDF/DOCX, incluindo estados de validação, geração e falha sem perda dos dados.
