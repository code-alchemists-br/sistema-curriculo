# Wireframe 03 — Dados pessoais e contato

## Campos
- Nome completo — obrigatório
- E-mail — obrigatório
- Telefone — obrigatório
- Cidade — obrigatório
- Meios profissionais de contato aplicáveis

## Ações
`Salvar rascunho` · `Salvar e continuar`

## Comportamentos
Indicar obrigatórios, validar junto ao campo, preservar dados em erro e permitir retorno para edição.
