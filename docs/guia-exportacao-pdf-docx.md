# Guia de Exportação de Currículos em PDF e DOCX

## 1. Objetivo

Este guia explica como funciona a exportação de currículos no Sistema Currículo, apresentando os formatos disponíveis, os cuidados antes de gerar o arquivo e as orientações para utilização dos documentos.

O sistema permite que o estudante organize suas informações pessoais, acadêmicas e profissionais em diferentes versões de currículo e utilize essas versões para gerar arquivos em PDF ou DOCX.

## 2. Formatos disponíveis

O Sistema Currículo oferece dois formatos de exportação:

| Formato | Extensão | Utilização recomendada |
|---|---|---|
| PDF | `.pdf` | Enviar o currículo para empresas, processos seletivos e plataformas de recrutamento, preservando sua apresentação |
| DOCX | `.docx` | Abrir o currículo em editores de texto compatíveis, permitindo ajustes posteriores no documento |

### 2.1. PDF

O PDF é indicado quando o estudante deseja compartilhar uma versão final do currículo.

Esse formato ajuda a preservar a disposição dos textos e elementos visuais, reduzindo diferenças de apresentação entre dispositivos e aplicativos.

### 2.2. DOCX

O DOCX é indicado quando o estudante precisa abrir o currículo em um editor de documentos, como Microsoft Word ou outro aplicativo compatível.

Esse formato permite realizar alterações posteriores no arquivo, embora a apresentação possa variar conforme o editor utilizado.

## 3. Preparação antes da exportação

Antes de exportar um currículo, recomenda-se verificar se as informações cadastradas estão corretas.

O estudante deve conferir principalmente:

1. Nome e informações de contato.
2. Formação acadêmica.
3. Experiências profissionais.
4. Competências e idiomas.
5. Projetos acadêmicos.
6. Itens selecionados para a versão do currículo.
7. Organização e ordem das seções.

Nem todas as versões precisam conter as mesmas informações. O estudante pode preparar versões diferentes conforme a oportunidade profissional desejada.

É importante conferir se a versão selecionada é realmente aquela que será utilizada na candidatura.

## 4. Seleção da versão do currículo

O Sistema Currículo permite manter diferentes versões associadas ao mesmo estudante.

A exportação utiliza a versão identificada pelo sistema no momento da solicitação.

Por isso, antes de gerar o arquivo, o estudante deve selecionar a versão desejada e verificar seu conteúdo na prévia, quando essa funcionalidade estiver disponível na interface.

A exportação de uma versão não deve alterar automaticamente os dados originais cadastrados no perfil.

## 5. Como exportar um currículo

O procedimento esperado para utilização pela interface web é:

1. Acessar o Sistema Currículo com sua conta.
2. Localizar a área de gerenciamento dos currículos.
3. Selecionar a versão que deseja exportar.
4. Conferir as informações e a apresentação do currículo.
5. Escolher o formato desejado, PDF ou DOCX.
6. Solicitar a exportação.
7. Salvar o arquivo disponibilizado pelo navegador.

**Observação:** a sequência acima representa o fluxo de utilização previsto para o estudante. A disponibilidade e os nomes definitivos dos controles da interface dependem da integração das funcionalidades de exportação ao frontend.

## 6. Exportação em PDF

Ao selecionar a opção de exportação em PDF, o sistema deve gerar um arquivo correspondente à versão de currículo escolhida.

O arquivo utiliza a extensão `.pdf` e o tipo de conteúdo `application/pdf`.

Depois de realizar o download, o estudante pode:

- abrir o documento em um leitor de PDF;
- conferir a apresentação das seções;
- verificar se todas as informações necessárias estão presentes;
- enviar o arquivo para empresas e processos seletivos.

Recomenda-se abrir o PDF antes do envio para verificar se os textos estão legíveis e se não ocorreram problemas na disposição do conteúdo.

## 7. Exportação em DOCX

Ao selecionar a opção de exportação em DOCX, o sistema deve gerar um documento correspondente à versão escolhida.

O arquivo utiliza a extensão `.docx` e pode ser aberto em programas compatíveis com esse formato.

Após o download, o estudante pode:

- abrir o documento em um editor de texto;
- revisar os dados apresentados;
- realizar ajustes no arquivo local;
- salvar a versão modificada.

As alterações realizadas diretamente no arquivo baixado não significam que os dados cadastrados no Sistema Currículo tenham sido atualizados.

Para modificar as informações utilizadas nas próximas exportações, o estudante deve realizar as alterações correspondentes no próprio sistema.

## 8. Diferenças entre PDF e DOCX

A escolha do formato depende da finalidade do currículo.

| Necessidade | Formato recomendado |
|---|---|
| Enviar currículo para uma vaga | PDF |
| Preservar a apresentação do documento | PDF |
| Abrir o currículo em um editor de texto | DOCX |
| Fazer alterações posteriores no arquivo | DOCX |
| Guardar uma cópia final para compartilhamento | PDF |

Caso a empresa solicite um formato específico, o estudante deve seguir essa orientação.

## 9. Problemas durante a exportação

Durante o processo de exportação podem ocorrer problemas relacionados à sessão, à versão selecionada ou à geração do arquivo.

### 9.1. Sessão encerrada ou inválida

A exportação exige autenticação.

Se a sessão não estiver válida, o estudante deverá realizar novamente o login antes de tentar exportar seu currículo.

### 9.2. Currículo não encontrado

Se a versão solicitada não existir ou não estiver disponível para o estudante autenticado, a exportação não será realizada.

Nesse caso, recomenda-se conferir a versão selecionada e tentar novamente com um currículo próprio.

### 9.3. Falha na geração do documento

Caso ocorra uma falha interna durante a geração, o sistema poderá apresentar a mensagem:

> Não foi possível gerar o arquivo. Tente novamente.

O estudante poderá realizar uma nova tentativa.

Se o problema continuar, deverá comunicar a equipe responsável pelo sistema.

### 9.4. Exportação indisponível

Uma funcionalidade de exportação pode estar temporariamente indisponível caso o serviço necessário para gerar o arquivo não esteja configurado ou disponível.

Nesse cenário, a solicitação não deve ser apresentada como download concluído.

### 9.5. Arquivo não abre corretamente

Se o arquivo for baixado, mas não abrir corretamente, recomenda-se:

1. Verificar se o download foi concluído.
2. Conferir se o arquivo possui a extensão esperada.
3. Utilizar um aplicativo compatível com PDF ou DOCX.
4. Realizar uma nova exportação, se necessário.

## 10. Segurança e privacidade

Os currículos podem conter informações pessoais, acadêmicas e profissionais.

Por isso, recomenda-se que o estudante:

- confira o conteúdo antes de compartilhar;
- evite disponibilizar documentos em locais públicos sem necessidade;
- mantenha cópias armazenadas em locais de confiança;
- remova arquivos de computadores compartilhados após sua utilização;
- verifique os dados solicitados pela empresa antes de enviar o currículo.

A exportação é restrita à versão pertencente ao estudante autenticado.

O conhecimento do identificador de outro currículo não concede autorização para exportá-lo.

## 11. Comportamento técnico atualmente implementado

O backend possui rotas específicas para exportação dos dois formatos.

| Operação | Método | Endpoint |
|---|---|---|
| Exportar DOCX | GET | `/estudantes/{usuario_id}/curriculos/{curriculo_id}/exportacao/docx` |
| Exportar PDF | GET | `/estudantes/{usuario_id}/curriculos/{curriculo_id}/exportacao/pdf` |

As rotas exigem uma sessão autenticada válida e verificam o acesso à versão solicitada.

Quando a geração ocorre corretamente, o backend devolve o conteúdo binário do arquivo, com o tipo MIME correspondente e os cabeçalhos necessários para download.

Os principais resultados previstos são:

| HTTP | Significado |
|---|---|
| `200 OK` | Arquivo gerado e devolvido |
| `401 Unauthorized` | Autenticação ausente ou inválida |
| `403 Forbidden` | Tentativa de acesso utilizando identificação de outro estudante |
| `404 Not Found` | Versão inexistente ou indisponível para o proprietário |
| `500 Internal Server Error` | Falha na geração do arquivo |
| `503 Service Unavailable` | Serviço de exportação não configurado |

Essas informações são apresentadas como referência técnica para manutenção e verificação do guia, não como procedimentos que o estudante precise executar manualmente.

## 12. Estado atual e limitações

A implementação atual possui casos de uso e rotas HTTP para exportação PDF e DOCX.

Entretanto, este documento não comprova que os controles de download já estejam integrados a todas as telas da interface web.

O procedimento apresentado na seção 5 descreve a experiência esperada para o estudante quando a integração estiver disponível.

A documentação deverá ser revisada quando o fluxo completo da interface estiver confirmado, incluindo os nomes dos botões e as etapas efetivamente apresentadas na tela.
